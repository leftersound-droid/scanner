# Operátordinamika

Ide kerülnek az önreflexív operátor közvetlen numerikus kísérletei: frontképződés, torlódás, visszaáramlás, perturbáció, dimenziófüggés és stabilitás.

Kritikus szabály: csak a kísérletben explicit módon definiált operátor és feltételek használhatók. Stabilizáló szabály, küszöb, fizikai törvény vagy egyéb mechanizmus nem adható hozzá utólag a kívánt eredmény érdekében.
