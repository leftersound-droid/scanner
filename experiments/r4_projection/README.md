# R4 → R3 projekció

Ide kerülnek azok a kísérletek, amelyek a mélyebb R4 relációs állapot és a választott R3 projekció kapcsolatát vizsgálják.

Jelenlegi tesztek:

- `latent_common_order/`: több nemlineáris projekcióból közös, orientációfüggetlen latens rendezés rekonstrukciója időcímke nélkül.
- az első lineárisabb komplement-kontroll egyelőre örökölt fájlként a `experiments/r4_complement_clock_probe.py` helyen marad.

A pozitív kontroll csak módszertani érzékenységet igazol; nem fizikai R4 vagy emergens idő bizonyítéka.
