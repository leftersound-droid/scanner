# Meta-stratégia és intuíciós réteg

Ide kerülnek a scanner saját működését vizsgáló tesztek: direkt vs analóg vs hibrid stratégia, pozitív/negatív/unresolved memória, részgráf-illesztés, ember által javasolt analógiák és stratégiai visszacsatolás.

A meta-réteg az elemzés módját hangolhatja, de nem módosíthatja a vizsgált tudományos operátort vagy adatot.
