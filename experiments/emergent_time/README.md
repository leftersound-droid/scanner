# Emergens idő

Ide kerülnek a belső órák, multi-clock összehasonlítások, állapotból rekonstruált rendezési paraméterek és projekciós időbizonytalanság vizsgálatai.

Elv: az iterációs index nem automatikusan fizikai idő. Az időjelöltet állapotból/relációkból kell rekonstruálni, majd külön tesztelni monotóniára, több belső folyamat közös paraméterezésére, dinamikai használhatóságra és reprezentációfüggésre.
