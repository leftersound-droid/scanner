# Elektromágneses jelleg

Ide kerülnek a töltés-, komplementer-pár-, dipólus-, E/B-projekciós és esetleges forrás/cirkulációs szerkezeteket vizsgáló kísérletek.

A címkék (`+`, `-`, `E`, `B`) lehetőleg csak a fenomenológiai megfeleltetés után kerüljenek rá a vakon rekonstruált relációs struktúrákra. A mintaegyezés hipotézis, nem azonosság.
