# Full R3 return rotating P/J orbit

Goal: test the revised compact-particle training hypothesis in which a compact R3 object is a closed rotating P/J pattern, while its R4 carrier may have a different compactness law.

## Training orbit

The R3 teacher is not a static scalar blob. A joint P/J pattern rotates in two R3 planes. The two partial periods are 4 and 6 operator frames, therefore the first full return of the complete R3 pattern is LCM(4,6)=12 frames. One full return is the minimum training length.

The prescribed J teacher co-rotates with the P pattern. It is only an analog/training input; after release it is removed and the unchanged self-reflexive operator evolves the state.

## R4 carrier families

The same R3 orbit is embedded in four R4 carrier families:

- compact: fixed w width
- linear: linearly increasing w width
- pulsing: periodically varying w width
- sqrt: sublinearly increasing w width

These are representation-family inputs, not operator laws.

## Readouts

Separate R3 and R4 compactness readouts are recorded: positive excess Q, R3 RMS radius, w RMS extent, projected R3 participation ratio PR3 and full R4 participation ratio PR4.

## Guardrails

No mass, energy, Compton, metric, Lorentz, stabilizer, damping or extra physical law is inserted. Iteration is not identified with physical time, J is not identified with velocity, and the R4 carrier family is not claimed to be physical. The pilot only asks which trained representation better preserves the projected R3 compactness after teacher removal.
