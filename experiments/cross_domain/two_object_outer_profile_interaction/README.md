# Two-object outer-profile interaction test

Status: diagnostic toy experiment, measurement-only interpretation.

Protocol used in the 2026-08-17 diagnostic:

1. Precondition one m=3 source object with the existing 1:1 phase-memory protocol.
2. Stop the imposed longitudinal phase drive and stop re-imposing the source wave.
3. Add an identical probe object at ±x, at separations 6, 7 and 8 lattice units.
4. Free-release the complete field under the unchanged self-reflexive operator.
5. Run a matched source-only branch and a probe-only homogeneous-background branch.
6. Isolate the probe contribution as `(source + probe) - source_only`; the subtraction is analysis only and never enters the operator.
7. Compare the isolated probe centroid with the probe-only control.

Observed relative displacement toward the source (lattice-coordinate units; short release):

| separation | +x mean | -x mean | +x final | -x final |
|---:|---:|---:|---:|---:|
| 6 | 0.022032 | 0.015333 | 0.017697 | 0.010280 |
| 7 | 0.026154 | 0.020658 | 0.024742 | 0.018684 |
| 8 | 0.026363 | 0.024119 | 0.025346 | 0.023043 |

Both sides show displacement toward the source relative to the probe-only control, so the sign is not explained by the intrinsic m=3 directional bias alone.

Interpretation limit: this establishes a short-run nonlinear interaction signature in the toy model. It does not yet establish a physical force law, distance law, attraction potential, mass law or gravity analogue.
