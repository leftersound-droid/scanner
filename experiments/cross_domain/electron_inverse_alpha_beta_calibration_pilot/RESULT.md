# Electron inverse alpha/beta calibration pilot — result

## Question
Can a family of taught P/J objects, evolved under the unchanged self-reflexive operator, produce dimensionless alpha/beta-cycle characteristics in the neighborhood of physically measured electron ratios, and does proximity to those target ratios correlate with improved free stability?

## Methodological status
This is a speculative inverse-calibration pilot, not a physical derivation.

The physical values are used only as external dimensionless targets. They are not inserted into the operator. The grid is only numerical representation. No grid distance, cell count, iteration count, torque, inertia, EM law, angular momentum law, damping, stabilizer, or extra synchronization term is interpreted as physical input.

The unchanged live-neighbour operator is used:

`Delta_ij = (P_i-P_j)_+`

`alpha_ij = Delta_ij / sum_k Delta_ik`

`beta_ij = Jprev_ij / sum_k Jprev_ik`

`C_i = mean(positive Delta_ij)`

`J_ij = C_i * alpha_ij / (1 + beta_ij)`

## External electron reference values
Two dimensionless electron quantities were used only as numerical comparison targets:

- fine-structure constant: `alpha_fs = 7.2973525643e-3`
- electron magnetic-moment anomaly: `a_e = 1.15965218046e-3`

No claim is made that either quantity has already been derived from the model.

## Candidate emergent characteristic readout
For each taught frame, local alpha and beta distributions were collapsed only over opposite direction pairs, producing four-component normalized direction-participation vectors:

`A(frame)` and `B(frame)`.

The full-cycle closure defects were then measured as dimensionless ratios:

`eps_alpha = ||A_end-A_start|| / sum ||A_{n+1}-A_n||`

`eps_beta  = ||B_end-B_start|| / sum ||B_{n+1}-B_n||`

These are candidate graph/directional cycle-characteristic quantities only. The mapping

`eps_alpha <-> alpha_fs`

`eps_beta <-> a_e`

is deliberately labeled speculative and was used only to test whether the selected object family naturally approaches the same orders of magnitude.

## Object-family sweep
The operator was not modified. Candidate objects were generated by varying only the teacher representation:

- one complete outer rotation period: `T_obj = 24, 32, 48, 64` sampled frames;
- internal longitudinal cycles per outer rotation: `1, 2, 4, 8, 12, 16`;
- tangential/longitudinal teacher-flow ratio: `1/16 ... 16` logarithmically.

After one complete taught cycle, all teacher forcing was removed and each case evolved freely for one nominal outer period.

## Numerical findings
Across the full sweep, the alpha/beta closure defects remained far above the electron target values:

- `eps_alpha` range: approximately `0.1045 .. 0.3846`
- `eps_beta` range: approximately `0.0453 .. 0.3491`

The best joint candidate was still far away in log-space from the electron targets. A representative closest case had approximately:

- `eps_alpha = 0.1357`
- beta closure of the same broad `10^-2 .. 10^-1` order
- marker retention after release about `0.140`
- concentration retention about `0.941`
- free orientation progression about `-0.075` cycles

Thus the tested alpha/beta-cycle defects are roughly one to two orders of magnitude larger than `alpha_fs`, and beta defects are typically much more than one order of magnitude larger than `a_e`.

## Stability result
No correlation was found in this pilot whereby moving closer to the electron target orders of magnitude produced a more stable released object.

Across the family:

- marker retention after one free period: about `0.14 .. 0.26`
- concentration retention: about `0.76 .. 0.94`
- no self-sustaining closed external rotation appeared
- no alpha/beta characteristic closure approached the selected electron target values

The released objects remained in the same broad relaxational regime.

## Important limitation: the user's path/diameter proposal is not yet testable correctly
The more physically motivated quantity suggested by the user — for example

`(emergent path travelled by an object point in one period) / (emergent object diameter)`

— was intentionally NOT evaluated here, because a validated emergent distance/diameter functional `d_em(P,J)` does not yet exist. Using grid radius or cell distance would violate the model's methodology by treating numerical embedding as physical geometry.

Therefore this pilot tests only alpha/beta-cycle-characteristic orders of magnitude. It does not yet test the stronger geometric/frequency calibration hypothesis.

## Interpretation
The result does not show that electron-like ratios are impossible in the model. It shows only that this particular simple taught object family does not naturally generate alpha/beta cycle-closure defects in the `10^-3 .. 10^-2` range while remaining dynamically stable.

The inverse-calibration program should therefore proceed in this order:

1. derive/test a representation-invariant emergent distance functional;
2. define emergent object diameter and emergent path length;
3. define an emergent period from P/J state recurrence rather than raw iteration;
4. construct physically meaningful dimensionless ratios from those emergent quantities;
5. only then compare those ratios with elementary-particle reference ratios and search for stability windows.

## Strongest justified conclusion

> In the tested object family, unchanged P/J dynamics produces alpha/beta cycle-characteristic defects of order `10^-1` to `10^-2`, not the selected electron `10^-3` to `10^-2` targets, and closeness to the targets does not improve free stability. The stronger electron-scale inverse test based on emergent path/diameter and emergent frequency ratios remains open because the required emergent metric/time readouts are not yet defined.
