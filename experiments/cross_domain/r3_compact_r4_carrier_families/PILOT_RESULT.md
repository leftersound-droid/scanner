# Pilot result — R3 compactness versus R4 carrier family

The causally isolated pilot used 8 training frames (4 imposed profile periods) followed by 2 free frames. The same compact R3 profile was trained with four R4-width histories.

At the last training frame the imposed/pre-operator `W_rms` values were visibly different: approximately 1.62 (`compact`), 1.95 (`linear`), 1.43 (`pulsing`), and 1.84 (`sqrt`). After the operator step the corresponding projected `R3_rms` values were all close, approximately 2.99–3.19.

Free-step ratios (second free readout / first free readout):

| R4 training family | R3_rms | W_rms | PR3 | PR4 |
|---|---:|---:|---:|---:|
| compact | 1.052 | 1.056 | 1.410 | 2.712 |
| linear | 1.044 | 1.016 | 4.199 | 4.182 |
| pulsing | 0.966 | 0.979 | 1.996 | 3.013 |
| sqrt | 1.045 | 1.017 | 5.024 | 5.442 |

## Interpretation

1. The four deliberately different R4 carrier histories do **not** map one-to-one onto the short-run projected R3 RMS size. The last-training R3 RMS values remain in a narrow band despite markedly different imposed fourth-coordinate widths.
2. The more sensitive participation readout (`PR3`) does retain a strong memory of the R4 training family after release. Thus equal/similar R3 RMS size is not enough to declare equal R3 object state.
3. None of the four cases is yet a stable compact particle: the participation volume changes strongly during release. This pilot therefore distinguishes **projectional RMS compactness** from **full relational compactness**.
4. The result supports testing R3 compactness independently from R4 compactness, but does not yet select compact, linear, pulsing, or sublinear R4 history as the physical one.
5. The next decisive run should extend training substantially and ask whether one family converges to a stationary/periodic projected `PR3`, recurrence class, and background correlation pattern while its R4 extent may remain nonstationary.
