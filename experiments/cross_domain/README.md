# Cross-domain experiments

Olyan kísérletek, amelyek több vizsgált terület invariánsait és korlátait egyszerre kapcsolják össze.

Ide kerülnek például az emergens idő–tömeg–töltés közös identifikációs tesztjei. A fizikai operátorhoz vagy adathoz itt sem adható hozzá új stabilizáló vagy fenomenológiai szabály.
