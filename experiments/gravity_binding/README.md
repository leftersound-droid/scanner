# Gravitáció és kötés

Ide kerülnek az Eötvös-analóg, effektív gravitációs, kötési és objektumcsaládok közti invarianciát vizsgáló tesztek.

A cél nem ismert gravitációs képletek beépítése, hanem annak vizsgálata, hogy a választott relációs reprezentáció milyen mértékben képes visszaadni vagy megkülönböztetni az ismert fenomenológiát.
