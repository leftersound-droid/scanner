# Work memory — continuous/emergent boundary and birth mechanism

Date: 2026-09-06
Status: **working hypothesis**, not an established physical law.

## Core reinterpretation

The early discrete “birth” mechanism should no longer be treated as literal creation of fundamental lattice points. The lattice is only a numerical representation. In the intended continuous model, the primitive state is

`P = P(x)`, `J = J(x,n)`

and numerical coordinates / iteration count are not physical distance or time.

“Birth” is reinterpreted as **emergent growth of the effective P/J-supported state volume**, while numerical point allocation is merely adaptive mesh growth.

## Finite local transfer

Keep the current self-reflexive transfer logic in continuous form:

`J(x,n) = C(x) * alpha(x,n) / (1 + beta(x,n)) * M(x,n)`

where `C` is local finite transfer capacity, `alpha` is derived from current positive P differences, and `beta` is derived from the previous actual local J distribution.

No external physical force law is added.

## Boundary / “vacuum resistance”

The higher resistance toward the unsupported / outward side is **not energetic dissipation**. It is lower directional mobility / flux capacity:

`J_out = J_local * mu_vac`, with `0 < mu_vac < 1`.

The key constraint is that `mu_vac` must not be a hand-chosen physical constant. It should be a self-reflexive characteristic derived from the local P/J configuration (the continuous analogue of the earlier ratio/capacity birth logic).

Thus P is not destroyed. If inward flux exceeds outward flux,

`dP_edge/ds = J_in - J_out > 0`,

so the boundary accumulates P automatically.

## Expected self-reflexive front cycle

A short P-only perturbation should be sufficient to trigger the process. J is never externally pumped; each frame it is recomputed from current P and previous actual J.

Expected cycle:

`delta P -> J_in -> boundary congestion -> P_edge rises -> outward capacity changes -> J_out rises -> effective supported volume grows faster -> edge gradient falls -> current catches up with front`.

The desired oscillation / front dynamics must be generated by the unchanged P/J operator, not by an externally imposed period, reflection rule, expansion law, threshold, stabilizer, or damping term.

## Perturbation

Global-generator teaching is a **short P injection only**:

`P(x,s) -> P(x,s) + eta(x,s)` for `0 < s < s_pert`, then `eta = 0`.

The research question is whether this finite perturbation alone can generate continuing front/growth dynamics.

## Temporary emergent readouts

Numerical iteration is only an update index. Candidate emergent readouts for present experiments:

- effective volume: `V_em = exp[- integral p ln(p) dmu]`, with `p = P / integral P dmu`;
- participation-ratio volume as a parallel check;
- provisional emergent time increment: `d tau_em = (integral J dmu / integral P dmu) ds`.

These are provisional readouts, not final definitions.

The front should not be identified by lattice radius. A first front readout may use a level set / maximum of a local P-to-outward-J relational characteristic. Hyperslab thickness should eventually be defined as a P/J correlation length or relational interval, not a cell count.

## Link to the R4 -> R3 hyperslab hypothesis

The global target remains:

`localized initial P state + short P perturbation -> growing R4 state domain -> boundary-attached lower-effective-dimensional R3-like hyperslab`.

The desired evidence is not a visually spherical shell on a grid, but a refinement-independent relational class with:

1. persistent boundary-dominated P/J structure;
2. a stable lower effective graph/correlation dimension;
3. congestion / acceleration / catch-up dynamics generated by the operator;
4. convergent `V_em(tau_em)` behavior;
5. eventually, an intrinsic quasi-periodic background mode capable of participating in object-background write/read feedback.

## Falsification rule

This version of the hypothesis is not supported if the desired front/hyperslab only appears after adding an explicit birth threshold, separate expansion law, artificial reflection, fixed vacuum constant, property-specific force, damping, synchronization, or stabilizer.

The implementation directive remains: **do not add such mechanisms without explicit agreement.**
